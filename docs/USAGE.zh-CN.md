# dsh-plugin-market 使用教程

这是一份面向普通 DSH 用户的快速教程：从安装插件市场，到通过插件市场安装、启用、停用和卸载其他插件。

## 1. 安装插件市场

在本机 DeepSeek Harness 环境中执行：

```bash
dsh plugin --profile web add github:uluckystar/dsh-plugin-market
```

然后重启 DSH，打开 Web 页面：

```text
http://127.0.0.1:3080/
```

进入：**设置 → 插件 → 插件市场**。

![插件市场分类浏览](./assets/market-browse.png)

## 2. 找插件

插件市场支持三种入口：

1. **分类浏览**：按 Agent、MCP、开发工具、界面、视觉、LLM、记忆、数据、集成等分类浏览。
2. **本地搜索**：输入关键词，快速匹配名称、简介和标签。
3. **AI 搜索**：勾选 🤖 AI 后，用自然语言描述需求，让 mydsh.dev 返回语义推荐。

![本地和 AI 搜索](./assets/market-search-ai.png)

## 3. 安装插件

点击插件右侧的「安装」。安装完成后，插件会进入「已安装·未启用」状态。

> 安装只表示“下载到当前 profile”，不会自动启用，也不会假装已经生效。

![安装流程](./assets/dsh-plugin-market-install-flow.gif)

## 4. 启用并生效

安装后点击「启用」。如果需要重启，页面会明确提示，并提供「立即重启生效」。

- 「已安装·未启用」：已经安装，但还没有加入启用列表。
- 「已启用·重启后生效」：配置已修改，等待重启。
- 「已启用」：当前运行中的 DSH 已经加载该插件。
- 「不兼容·不建议启用」：插件与当前环境冲突，市场会阻止启用，避免把 DSH 启坏。

![已安装状态](./assets/market-installed.png)

## 5. 停用或卸载

- **停用**：从启用列表移除，但保留安装，之后可以重新启用。
- **卸载**：移除安装，并清理启用状态。

所有会改配置的操作都会先做确认，并在写入前备份配置；写入后会重新校验，失败会回滚。

## 6. 当前公开校验口径

当前插件市场只展示已经确认可以直接启用的 DSH 插件：

- 候选仓库：5596 个
- 严格有效：3656 个
- 已隐藏无效项：1940 个
- 跳过项：0 个

校验依据是仓库 `package.json` 中声明了可直接启用的 DSH bundle。纯界面包、不完整仓库、不可解析仓库不会展示，也不会被安装入口放行。
