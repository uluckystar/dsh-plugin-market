# dsh-plugin-market 安全重启说明

DSH Web 不应直接绑定 `0.0.0.0`。当前 DSH 会主动拒绝该参数，因为 Web UI 具备本机文件、命令与 Agent 操作能力，裸露到网络存在高风险。

插件市场的一键重启会复用当前进程参数。为避免后续智能体或外部脚本误把 `--host 0.0.0.0` 带入重启链路，插件市场会在自动重启前移除该危险参数，回到 DSH 默认的本机监听方式。

正确远程访问方式：

- SSH Tunnel
- Tailscale / NetBird 私网后再访问
- 带认证的反向代理

不要通过修改 DSH 启动参数暴露到整个局域网。
